# Перспективы привлечения финансирования AI-стартапами через краудфандинг

## О проекте

Репозиторий содержит полный цикл сбора и анализа данных для исследования факторов, связанных с результатами краудфандинга AI-стартапов. В работе рассматривается, как характеристики коммуникации кампании, опыт основателя, использование AI-терминологии и технологическая легитимность страны происхождения связаны с привлечением финансирования на платформе Kickstarter.

Проект объединяет автоматизированный веб-скрапинг на Python, разведочный анализ данных и эконометрическое моделирование в R. Итоговая аналитическая выборка включает **756 AI-проектов из категории Technology, завершившихся с января 2021 года по март 2026 года**.

## Исследовательский вопрос

**Как характеристики презентации кампании, опыт основателя, AI-сигналинг и технологическая легитимность страны связаны с успешностью привлечения финансирования AI-стартапами?**

Теоретическую основу исследования составляют теория сигналов и теория социального присутствия. В условиях информационной асимметрии потенциальные спонсоры не могут непосредственно оценить техническое качество AI-продукта, поэтому могут полагаться на наблюдаемые сигналы, представленные на странице кампании.

## Этапы исследования

1. **Сбор данных:** информация о кампаниях Kickstarter собрана с публично доступных страниц с помощью автоматизированного парсера на Python.
2. **Подготовка данных:** наблюдения очищены, преобразованы и объединены с ежегодными значениями Global Innovation Index.
3. **Разведочный анализ:** в Python исследованы распределения кампаний, переменных, стран, технологических подкатегорий и результатов краудфандинга.
4. **Эконометрический анализ:** в качестве основной спецификации в R оценены модели OLS.
5. **Анализ взаимодействия:** проверена модерирующая роль Global Innovation Index во взаимосвязи между AI-сигналингом и результатами краудфандинга.
6. **Проверка устойчивости:** построена логистическая регрессия с бинарным индикатором успешности кампании в качестве альтернативной зависимой переменной.
7. **Дополнительный анализ:** с помощью квантильной регрессии проверено, различаются ли оцениваемые взаимосвязи на разных участках условного распределения результатов краудфандинга.

## Сбор данных и формирование выборки

Данные кампаний собраны с использованием **Python 3.14**, **BeautifulSoup** и **Playwright**. Проекты включались в выборку при соответствии следующим критериям:

- название кампании содержит термин `AI`;
- кампания относится к категории Technology на Kickstarter;
- кампания имеет итоговый статус successful или failed;
- используется модель краудфандинга, основанная на вознаграждении;
- кампания завершилась в период с января 2021 года по март 2026 года.

Первоначальная выборка состояла из 1 000 кампаний: 500 успешных и 500 неуспешных проектов. После удаления наблюдений с пропущенными значениями и ограничения периода в соответствии с доступностью данных Global Innovation Index итоговая выборка составила **756 кампаний из 38 стран и 15 технологических подкатегорий**.

> Сбалансированная выборка сформирована для обеспечения достаточной вариативности результатов кампаний. Поэтому оценки моделей следует интерпретировать как взаимосвязи внутри сформированной аналитической выборки, а не как оценки вероятности успеха генеральной совокупности кампаний Kickstarter.

## Основные переменные

### Зависимые переменные

- **Funding ratio:** отношение привлечённой суммы к заявленной цели кампании.
- **Log funding ratio:** `log(1 + funding ratio)`, зависимая переменная в моделях OLS и квантильной регрессии.
- **Успешность кампании:** бинарный индикатор, равный 1, если кампания достигла цели финансирования, и 0 в противном случае; используется в логистических моделях для проверки устойчивости.

### Объясняющие переменные

- количество внешних ссылок в описании кампании;
- наличие раздела FAQ;
- количество AI-терминов в описании кампании;
- наличие у основателя опыта запуска проектов на Kickstarter;
- Global Innovation Index страны происхождения кампании.

### Контрольные переменные

- продолжительность кампании;
- длина названия;
- наличие видео;
- количество изображений;
- количество терминов, связанных с компетенциями основателя.

Для переменных со скошенными распределениями применено преобразование `log(x + 1)`. Перед построением переменной взаимодействия количество AI-терминов и Global Innovation Index центрированы относительно среднего значения.

## Методы

Основной анализ выполнен в **R 4.4.3**. Модели OLS оценены с помощью пакета `fixest` с гетероскедастически устойчивыми стандартными ошибками. Регрессионные таблицы сформированы с использованием `modelsummary`.

Оценены три основные спецификации:

1. модель только с контрольными переменными;
2. полная модель с основными объясняющими переменными;
3. полная модель с взаимодействием между AI-сигналингом и Global Innovation Index.

Для всех спецификаций OLS рассчитаны факторы инфляции дисперсии: все значения VIF оказались ниже 5, что не указывает на серьёзную проблему мультиколлинеарности. Для проверки устойчивости результатов построена логистическая регрессия с бинарным индикатором успешности кампании. Квантильная регрессия использована как дополнительный анализ неоднородности взаимосвязей на разных уровнях результатов краудфандинга.

## Основные результаты

- **Внешние ссылки:** количество внешних ссылок положительно и статистически значимо связано с результатами краудфандинга. В полной модели OLS одна дополнительная ссылка связана приблизительно с **8,44% более высоким ожидаемым значением funding ratio плюс один** при прочих равных условиях.
- **Раздел FAQ:** ожидаемое значение funding ratio плюс один для кампаний с разделом FAQ приблизительно на **176,21% выше**, чем для кампаний без FAQ, при прочих равных условиях.
- **Опыт основателя:** предшествующий опыт запуска проектов на Kickstarter положительно связан с результатами кампании. В полной модели OLS ожидаемое значение funding ratio плюс один для кампаний опытных основателей приблизительно на **120,34% выше**, чем для кампаний основателей без такого опыта, при прочих равных условиях.
- **AI-сигналинг:** частота использования AI-терминологии статистически незначима как в основной модели OLS, так и в логистической модели. Следовательно, результаты не подтверждают положительную связь между повторным использованием AI-терминов и результатами краудфандинга.
- **Эффект взаимодействия:** взаимодействие между AI-сигналингом и Global Innovation Index имеет отрицательный и статистически значимый коэффициент в модели OLS. Это указывает на ослабление взаимосвязи между AI-сигналингом и результатами краудфандинга по мере увеличения технологической легитимности страны. Однако в логистической модели коэффициент взаимодействия статистически незначим, поэтому результат **не является устойчивым к изменению спецификации модели**.

В целом результаты показывают, что прозрачность, качество коммуникации кампании и опыт основателя более последовательно связаны с результатами краудфандинга, чем частота использования AI-терминологии.

## Содержимое репозитория

- **Парсер на Python:** автоматизированный сбор публично доступных данных о кампаниях Kickstarter.
- **EDA на Python:** очистка данных, описательная статистика, анализ распределений и разведочные визуализации.
- **Анализ в R:** преобразование переменных, описательный анализ, модели OLS, анализ взаимодействия, логистическая проверка устойчивости, квантильная регрессия, итоговые таблицы и графики.
- **Исследовательская работа:** полное описание теоретической основы, гипотез, методологии, результатов, обсуждения и ограничений.

## Воспроизводимость

Для воспроизведения анализа необходимы:

- Python 3.14;
- BeautifulSoup;
- Playwright;
- R 4.4.3;
- `fixest`;
- `modelsummary`;
- остальные пакеты R, подключённые в аналитических скриптах.

Парсер собирает данные с действующих веб-страниц, поэтому результат может измениться, если Kickstarter обновит структуру сайта либо страницы кампаний будут изменены или удалены. Перед запуском парсера необходимо проверить актуальные условия использования Kickstarter и применимые требования к сбору данных. Также может потребоваться изменение путей к файлам в соответствии с локальной структурой проекта.

## Ограничения

- AI-проекты определялись по наличию термина `AI` в названии кампании, поэтому некоторые релевантные проекты могли не попасть в выборку, а поверхностно использующие термин проекты могли быть включены.
- Сбалансированная стратегия формирования выборки не воспроизводит фактическую долю успешных кампаний на Kickstarter.
- Выборка ограничена reward-based кампаниями категории Technology и географически сконцентрирована в США.
- Словарные показатели AI-терминологии и компетенций основателя могут содержать ошибки классификации.
- Показатель внешних ссылок может включать повторяющиеся или автоматически созданные платформой ссылки.
- Наблюдательный дизайн исследования не позволяет делать причинные выводы; также нельзя исключить смещение из-за пропущенных переменных.
